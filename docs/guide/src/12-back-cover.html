LeakLab · Field Guide

"A JVM can only save you
if its safety net hangs below
the container's trapdoor."

LeakLab runs one container image four ways and lets you watch each one fail: a leak the JVM catches, a kill nobody saw coming, a kill hidden behind a sensible-looking percentage, and a leak no heap dump can show. Every step is explained twice, first precisely, then like you're five, and verified on the Red Hat build of OpenJDK, IBM Semeru, Oracle Java and Eclipse Temurin, on Java 17, 21 and 25.
